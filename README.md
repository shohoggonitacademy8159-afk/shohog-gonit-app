# সহগ গণিত একাডেমি — অ্যাপ

শিক্ষার্থীদের ফোনে ইন্সটল করার অ্যান্ড্রয়েড অ্যাপ (APK) এবং পিসি থেকে পরিচালনার ওয়েব সংস্করণ।

- **শিক্ষার্থী:** APK ইন্সটল করে খুললেই হোম, শ্রেণি, রুটিন ও সিলেবাস দেখবে। লগইন লাগবে না।
- **অ্যাডমিন:** অ্যাপের "আরো" → "অ্যাডমিন লগইন" থেকে ঢুকে রুটিন ও সিলেবাস প্রকাশ। এখনই বা নির্দিষ্ট সময়ে।
- **ডেটা:** Google Firebase (Firestore)। সবাই পড়তে পারে, শুধু অ্যাডমিন লিখতে পারে। অ্যাডমিনের ইমেইল শুধু Firebase কনসোলের Rules-এ থাকে, অ্যাপ বা এই রিপোতে নয়।

## কীভাবে কাজ করে

1. `main` শাখায় কোনো পরিবর্তন গেলেই GitHub Actions নিজে থেকে APK বানায়।
2. APK পাওয়া যায় **Releases** পাতায়। সবসময়ের সর্বশেষ APK-এর লিংক:
   `https://github.com/shohoggonitacademy8159-afk/shohog-gonit-app/releases/latest/download/sohog-ganit-academy.apk`
3. একই সাথে ওয়েব সংস্করণ GitHub Pages-এ যায়, পিসি থেকে অ্যাডমিন কাজের জন্য।

## ফাইল

| ফাইল | কাজ |
|---|---|
| `www/index.html` | অ্যাপের পুরো পাতা (`src/transform.py` দিয়ে তৈরি) |
| `www/config.js` | Firebase সংযোগ |
| `src/db.js` | Firebase-এর সাথে যোগাযোগ |
| `firestore.rules` | নিয়মের নমুনা (`ADMIN_EMAIL` জায়গায় আসল ইমেইল বসিয়ে কনসোলে দিতে হয়) |
| `signing/sohog-release.p12` | APK সই করার চাবি (পাসওয়ার্ড শুধু GitHub Secret-এ) |
| `.github/workflows/build.yml` | স্বয়ংক্রিয় APK ও ওয়েব তৈরি |

> সতর্কতা: `signing/sohog-release.p12` ফাইল আর তার পাসওয়ার্ড হারাবেন না। এটা বদলে গেলে শিক্ষার্থীদের পুরনো অ্যাপ মুছে নতুন করে ইন্সটল করতে হবে।
