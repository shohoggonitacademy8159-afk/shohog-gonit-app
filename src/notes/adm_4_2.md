# সরলরেখা: ভার্সিটি এডমিশনের শর্টকাট

## ১. বিন্দু সংক্রান্ত মৌলিক সূত্র

| বিষয় | সূত্র |
|---|---|
| দূরত্ব | √[(x₂−x₁)² + (y₂−y₁)²] |
| মধ্যবিন্দু | ((x₁+x₂)/2, (y₁+y₂)/2) |
| অন্তর্বিভক্ত বিন্দু (m:n) | ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n)) |
| বহির্বিভক্ত বিন্দু (m:n) | ((mx₂−nx₁)/(m−n), (my₂−ny₁)/(m−n)) |
| ভরকেন্দ্র | ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3) |

**অনুপাতের শর্টকাট:**

- x-অক্ষ (x₁,y₁) ও (x₂,y₂) বিন্দুর সংযোগ রেখাকে **−y₁ : y₂** অনুপাতে ভাগ করে।
- y-অক্ষ একই রেখাকে **−x₁ : x₂** অনুপাতে ভাগ করে।
- ax+by+c=0 রেখাটি একই সংযোগ রেখাকে **−(ax₁+by₁+c) : (ax₂+by₂+c)** অনুপাতে ভাগ করে।

উত্তর ধনাত্মক এলে অন্তর্বিভক্ত, ঋণাত্মক এলে বহির্বিভক্ত।

**সমকোণী ত্রিভুজের শর্টকাট:**

- লম্ববিন্দু (orthocenter) হলো সমকোণের শীর্ষবিন্দু।
- পরিকেন্দ্র (circumcenter) হলো অতিভুজের মধ্যবিন্দু।

## ২. ক্ষেত্রফল

**ত্রিভুজ:** ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|

**চতুর্ভুজ বা বহুভুজ:** শীর্ষবিন্দুগুলো ঘড়ির কাঁটার বিপরীত দিকে ক্রমানুসারে লেখো, শেষে প্রথম বিন্দুটি আবার লেখো। তারপর ক্রস গুণ করো:
½ |(x₁y₂ − x₂y₁) + (x₂y₃ − x₃y₂) + …|

**সমরেখ হওয়ার শর্ত:** তিনটি বিন্দু এক সরলরেখায় থাকলে ক্ষেত্রফল = 0, অর্থাৎ যেকোনো দুই জোড়া বিন্দুর ঢাল সমান।

## ৩. ঢাল (Slope)

- দুটি বিন্দু দেওয়া থাকলে: m = (y₂−y₁)/(x₂−x₁)
- রেখাটি x-অক্ষের সাথে θ কোণ তৈরি করলে: m = tanθ
- **ax + by + c = 0 আকারের রেখায়: m = −a/b**
  মনে রাখার কৌশল: ঢাল = −(x-এর সহগ)/(y-এর সহগ)

| রেখা | ঢাল |
|---|---|
| x-অক্ষের সমান্তরাল | 0 |
| y-অক্ষের সমান্তরাল | অসংজ্ঞায়িত |
| সমান্তরাল দুটি রেখা | m₁ = m₂ |
| লম্ব দুটি রেখা | m₁ × m₂ = −1 |

## ৪. সরলরেখার সমীকরণ

| ধরন | সমীকরণ |
|---|---|
| ঢাল–ছেদক | y = mx + c |
| এক বিন্দু ও ঢাল | y − y₁ = m(x − x₁) |
| দুই বিন্দু | (y−y₁)/(y₁−y₂) = (x−x₁)/(x₁−x₂) |
| ছেদক আকার | x/a + y/b = 1 |
| লম্ব আকার | x cosα + y sinα = p |

## ৫. ছেদক ও অক্ষের সাথে ত্রিভুজ

ax + by + c = 0 রেখার জন্য:

- x-অক্ষের ছেদক = **−c/a**
- y-অক্ষের ছেদক = **−c/b**
- রেখাটি অক্ষদ্বয়ের সাথে যে ত্রিভুজ তৈরি করে তার ক্ষেত্রফল = **c² / (2|ab|)**

উদাহরণ: 3x + 4y − 12 = 0 রেখার ক্ষেত্রফল = 144/(2×12) = **6 বর্গ একক**।

**বিশেষ ক্ষেত্র:**

- অক্ষদ্বয় থেকে সমান ছেদক কাটলে: x + y = a
- সমান মানের কিন্তু বিপরীত চিহ্নের ছেদক কাটলে: x − y = a
- (h, k) বিন্দুতে রেখাটির অক্ষদ্বয়ের মধ্যবর্তী অংশ সমদ্বিখণ্ডিত হলে: **x/(2h) + y/(2k) = 1**, অর্থাৎ **x/h + y/k = 2**

## ৬. সমান্তরাল ও লম্ব রেখা (সবচেয়ে বেশি আসে)

প্রদত্ত রেখা ax + by + c = 0 হলে:

| চাওয়া রেখা | সমীকরণ |
|---|---|
| সমান্তরাল রেখা | ax + by + k = 0 (শুধু ধ্রুবক বদলাবে) |
| লম্ব রেখা | bx − ay + k = 0 (সহগ দুটি অদলবদল করে একটির চিহ্ন বদলাও) |
| (x₁,y₁) বিন্দুগামী সমান্তরাল রেখা | a(x−x₁) + b(y−y₁) = 0 |
| (x₁,y₁) বিন্দুগামী লম্ব রেখা | b(x−x₁) − a(y−y₁) = 0 |

উদাহরণ: (1, 2) বিন্দুগামী এবং 3x + 4y = 5 রেখার ওপর লম্ব রেখা নির্ণয় করো।
4(x−1) − 3(y−2) = 0, অর্থাৎ **4x − 3y + 2 = 0**। পুরো হিসাব এক লাইনেই শেষ।

## ৭. দুই রেখার মধ্যবর্তী কোণ

tanθ = |(m₁ − m₂) / (1 + m₁m₂)|

- 1 + m₁m₂ = 0 হলে কোণটি 90°।
- রেখা দুটি a₁x+b₁y+c₁=0 ও a₂x+b₂y+c₂=0 আকারে থাকলে: tanθ = |(a₂b₁ − a₁b₂)/(a₁a₂ + b₁b₂)|
  এখানে **a₁a₂ + b₁b₂ = 0** হলে রেখা দুটি পরস্পর লম্ব।

## ৮. দূরত্বের সূত্র

**বিন্দু থেকে রেখার লম্ব দূরত্ব:**
d = |ax₁ + by₁ + c| / √(a² + b²)

**মূলবিন্দু থেকে রেখার দূরত্ব:** |c| / √(a² + b²)

**দুটি সমান্তরাল রেখার মধ্যবর্তী দূরত্ব:**
d = |c₁ − c₂| / √(a² + b²)

সতর্কতা: সূত্রটি প্রয়োগের আগে দুই রেখার x ও y-এর সহগ একই করে নিতে হবে।
উদাহরণ: 3x+4y+5=0 ও 6x+8y+20=0 রেখা দুটির ক্ষেত্রে দ্বিতীয়টিকে 2 দিয়ে ভাগ করলে পাওয়া যায় 3x+4y+10=0। তাহলে d = |5−10|/5 = **1**।

## ৯. লম্বের পাদবিন্দু ও প্রতিবিম্ব

(x₁, y₁) বিন্দু এবং ax + by + c = 0 রেখার জন্য:

**লম্বের পাদবিন্দু (h, k):**
(h−x₁)/a = (k−y₁)/b = **−(ax₁+by₁+c)/(a²+b²)**

**প্রতিবিম্ব (h, k):**
(h−x₁)/a = (k−y₁)/b = **−2(ax₁+by₁+c)/(a²+b²)**

**বিশেষ প্রতিবিম্ব (মুখস্থ রাখো):**

| যে রেখা বা বিন্দুর সাপেক্ষে | (x, y)-এর প্রতিবিম্ব |
|---|---|
| x-অক্ষ | (x, −y) |
| y-অক্ষ | (−x, y) |
| মূলবিন্দু | (−x, −y) |
| y = x | (y, x) |
| y = −x | (−y, −x) |

## ১০. ছেদবিন্দু ও সমবিন্দুতা

- দুটি রেখা L₁ = 0 ও L₂ = 0-এর ছেদবিন্দুগামী যেকোনো রেখা: **L₁ + kL₂ = 0**। এরপর অন্য শর্ত দিয়ে k বের করো।
- তিনটি রেখা একই বিন্দুতে মিলিত হওয়ার (সমবিন্দু) শর্ত:
  |a₁ b₁ c₁; a₂ b₂ c₂; a₃ b₃ c₃| = 0

## ১১. বিন্দু রেখার কোন পাশে

দুটি বিন্দুর স্থানাঙ্ক ax + by + c রাশিতে বসাও:

- দুটির মান একই চিহ্নের হলে বিন্দু দুটি রেখার **একই পাশে**।
- বিপরীত চিহ্নের হলে বিন্দু দুটি রেখার **বিপরীত পাশে**।

## ১২. কোণের সমদ্বিখণ্ডক

(a₁x + b₁y + c₁)/√(a₁²+b₁²) = ±(a₂x + b₂y + c₂)/√(a₂²+b₂²)

c₁ ও c₂ দুটোই ধনাত্মক করে নেওয়ার পর:

- **+** চিহ্ন নিলে মূলবিন্দু-ধারী কোণের সমদ্বিখণ্ডক পাওয়া যায়।
- **−** চিহ্ন নিলে অন্য কোণের সমদ্বিখণ্ডক পাওয়া যায়।

## MCQ ট্রিক

1. **অপশন যাচাই:** প্রশ্নের প্রদত্ত বিন্দুটি প্রতিটি অপশনের সমীকরণে বসাও। যে সমীকরণ বিন্দুটি দ্বারা সিদ্ধ হয় না, সেটি বাদ দাও।
2. **ঢাল দিয়ে বাদ দেওয়া:** প্রশ্নে সমান্তরাল বা লম্ব রেখা চাইলে আগে প্রতিটি অপশনের ঢাল দেখো। ভুল অপশনগুলো এভাবেই অর্ধেক কমে যায়।
3. **দূরত্বের প্রশ্নে √(a²+b²):** এই মান প্রায়ই 5, 13, 10-এর মতো পূর্ণসংখ্যা হয়। তাই (3,4,5), (5,12,13), (6,8,10) ত্রয়ীগুলো চিনে রাখো।
