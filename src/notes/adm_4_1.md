# ম্যাট্রিক্স ও নির্ণায়ক: ভার্সিটি এডমিশনের শর্টকাট

## ১. ম্যাট্রিক্সের বেসিক শর্টকাট

**গুণ করা যাবে কিনা:** (m×**n**) × (**n**×p) = m×p। মাঝের সংখ্যা দুটি সমান হলেই গুণ করা যায়, আর ফলাফলের ক্রম হয় বাইরের দুই সংখ্যা।

**সম্ভাব্য ক্রম:** কোনো ম্যাট্রিক্সে n টি উপাদান থাকলে তার সম্ভাব্য ক্রমের সংখ্যা n-এর উৎপাদক বা ভাজকের সংখ্যার সমান।
উদাহরণ: ১২টি উপাদান থাকলে ক্রম হতে পারে ১×১২, ২×৬, ৩×৪, ৪×৩, ৬×২, ১২×১। মোট ৬টি।

**বিশেষ ম্যাট্রিক্স (মুখস্থ রাখো):**

| নাম | শর্ত |
|---|---|
| প্রতিসম (Symmetric) | Aᵀ = A |
| বিপ্রতিসম (Skew-symmetric) | Aᵀ = −A (কর্ণের সব উপাদান 0) |
| Idempotent | A² = A |
| Involutory | A² = I |
| Nilpotent | Aᵏ = O |
| ব্যতিক্রমী (Singular) | \|A\| = 0 (বিপরীত ম্যাট্রিক্স নেই) |

## ২. ২×২ ম্যাট্রিক্সের দ্রুত সূত্র

A = [a b; c d] হলে:

- **নির্ণায়ক:** |A| = ad − bc
- **বিপরীত ম্যাট্রিক্স:** a আর d-এর জায়গা বদলাও, b আর c-এর চিহ্ন বদলাও, তারপর |A| দিয়ে ভাগ করো।
  A⁻¹ = 1/(ad−bc) × [d −b; −c a]
- **A² বের করার শর্টকাট (Cayley–Hamilton):**
  **A² = (a+d)·A − (ad−bc)·I**
  এখানে a+d হলো কর্ণের যোগফল বা trace।
- **ঘাতের শর্টকাট:** [1 a; 0 1]ⁿ = [1 na; 0 1]
- **কর্ণ ম্যাট্রিক্সের ঘাত:** কর্ণের প্রতিটি উপাদানের আলাদা আলাদা ঘাত নিলেই হয়।

## ৩. ৩×৩ নির্ণায়ক: সারাস (Sarrus) নিয়ম

প্রথম দুই কলাম ডানে আবার লেখো।

- বাম থেকে ডানে নিচের দিকের তিনটি কর্ণের গুণফল যোগ করো (+)।
- ডান থেকে বামে নিচের দিকের তিনটি কর্ণের গুণফল বিয়োগ করো (−)।

**ত্রিভুজাকার বা কর্ণ ম্যাট্রিক্সের নির্ণায়ক = কর্ণের উপাদানগুলোর গুণফল।** এখানে কিছু হিসাব করতেই হয় না।

## ৪. নির্ণায়কের ধর্ম (MCQ-তে সবচেয়ে বেশি আসে)

- দুটি সারি বা কলাম সমান কিংবা সমানুপাতিক হলে মান **0**।
- কোনো সারি বা কলামের সব উপাদান 0 হলে মান **0**।
- দুটি সারি অদলবদল করলে **চিহ্ন বদলে যায়**।
- একটি সারিকে k দিয়ে গুণ করলে নির্ণায়কও k গুণ হয়।
- **|kA| = kⁿ|A|** (n হলো ক্রম)। ৩×৩ ম্যাট্রিক্সে |2A| = 8|A|।
- বিজোড় ক্রমের বিপ্রতিসম ম্যাট্রিক্সের নির্ণায়ক = **0**।

**গুরুত্বপূর্ণ সূত্র (n×n ম্যাট্রিক্সের জন্য):**

| সূত্র | মান |
|---|---|
| \|Aᵀ\| | \|A\| |
| \|AB\| | \|A\|·\|B\| |
| \|A⁻¹\| | 1/\|A\| |
| \|adj A\| | \|A\|ⁿ⁻¹ |
| adj(adj A) | \|A\|ⁿ⁻² · A |
| \|adj(adj A)\| | \|A\|<sup>(n−1)²</sup> |
| A·adj A | \|A\|·I |

উদাহরণ: ৩×৩ ম্যাট্রিক্সে |A| = 5 হলে |adj A| = 5² = 25।

## ৫. বিশেষ নির্ণায়ক প্যাটার্ন (দেখামাত্র উত্তর লেখো)

| নির্ণায়ক | মান |
|---|---|
| \|1 1 1; a b c; a² b² c²\| | (a−b)(b−c)(c−a) |
| \|1 1 1; a b c; a³ b³ c³\| | (a−b)(b−c)(c−a)(a+b+c) |
| \|a b c; b c a; c a b\| | 3abc − (a³+b³+c³) |
| \|x a a; a x a; a a x\| | (x+2a)(x−a)² |
| \|1+a 1 1; 1 1+b 1; 1 1 1+c\| | abc + ab + bc + ca |

## ৬. সবচেয়ে কাজের MCQ ট্রিক

**ট্রিক ১: মান বসিয়ে যাচাই করা।**
অপশনগুলো a, b, c দিয়ে লেখা থাকলে a = 0, b = 1, c = 2-এর মতো ছোট মান বসাও। তারপর নির্ণায়ক আর অপশন দুটোরই মান বের করে মিলিয়ে নাও।
যেমন |1 1 1; a b c; a³ b³ c³|-এ a=0, b=1, c=2 বসালে মান 6 আসে। যে অপশনের মান 6 সেটাই উত্তর।

**ট্রিক ২: x-এর মূল খোঁজা।**
নির্ণায়কে x থাকলে x-এর এমন মান খোঁজো যাতে দুটি সারি বা কলাম সমান হয়ে যায়। ওই মানটাই একটি মূল।
x-এর ঘাত দেখে মোট মূলের সংখ্যা বোঝা যায়।

**ট্রিক ৩: সারির যোগফল সমান হলে।**
প্রতিটি সারির যোগফল একই হলে C₁ → C₁+C₂+C₃ করো। তাতে প্রথম কলামের সাধারণ উৎপাদকটি সরাসরি বাইরে চলে আসে।

**ট্রিক ৪: ব্যতিক্রমী ম্যাট্রিক্স।**
"ম্যাট্রিক্সটি ব্যতিক্রমী হলে x = ?" ধরনের প্রশ্নে |A| = 0 বসিয়ে সমীকরণটি সমাধান করো।

## ৮. সমীকরণ জোট (ক্রেমারের নিয়ম)

x = D<sub>x</sub>/D, y = D<sub>y</sub>/D, z = D<sub>z</sub>/D

- D ≠ 0 হলে একটিমাত্র (অনন্য) সমাধান থাকে।
- D = 0 এবং D<sub>x</sub> = D<sub>y</sub> = D<sub>z</sub> = 0 হলে অসংখ্য সমাধান থাকে, অথবা কোনো সমাধান থাকে না।
- D = 0 এবং অন্তত একটি D<sub>i</sub> ≠ 0 হলে কোনো সমাধান নেই।

## ৯. জ্যামিতিতে নির্ণায়ক
